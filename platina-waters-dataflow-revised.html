What changed, and why

The InstaMedia map was built for social publishing: Instagram reels, hashtag harvesting, engagement z-scores, a posting scheduler. Waters does none of that. Waters runs digital campaigns, brand programmes and in-person events — conferences, symposia, trade shows — with an outcome signal measured in pipeline, not likes.

02

Three planes, not two

The original rule kept measured first-party data apart from scraped public content. That rule still holds — but the Brain introduces a third category the old model had no name for: reasoning derived from market signal. It is not raw signal, and it is not measured truth. Giving it its own plane is what keeps the honesty property intact.

04

The contradiction layer

Two models, different providers, different prompts, opposing objectives. One proposes a driver — "this topic is drawing attention because it addresses a method-validation pain point" — and the other is instructed to attack it: propose a confounder, name what the evidence cannot support, argue the null.

Why this runs before vectorization

Vector chunks are retrieved independently. Embed a claim and its refutation and nothing guarantees they co-retrieve — a refuted claim can surface alone, stripped of the thing that killed it. That is worse than not debating at all. Contradiction is a write-time quality gate: resolve first, embed the resolved insight, keep the transcript stored but unembedded and linked by ID.

Resolution states

StateConfidenceWhat happens
agreed0.7 – 1.0Embedded into the Brain, usable as a hypothesis in ideation
qualified0.4 – 0.7Embedded with the challenger's caveat attached to the chunk text itself
contested< 0.4Escalated to a human. Not embedded until someone rules
refuted—Transcript retained for audit. Never embedded. Never retrievable
 
// contradiction gate — bounded, deterministic termination
const claim   = await routeAI({ role: "proposer",  model: A, input: rawSignal });
const attack  = await routeAI({ role: "challenger", model: B, input: { rawSignal, claim } });

// deterministic — not a model decision
const score = resolve(claim, attack);      // evidence span overlap, specificity, confounder strength

if (score < CONTESTED_FLOOR)  return escalateToHuman(claim, attack);
if (score < QUALIFIED_FLOOR)  claim.caveat = attack.strongestObjection;

// exactly one round. no code path requests a second.
return embedIntoBrain({ ...claim, score, sourceIds, transcriptId, generation: 0 });
Accountability, as the guardrails define it

One round, fixed in code. Full chain logged — both positions, the deterministic score, the resolution, and the human ruling where there was one. A named owner starts the run and can halt it at any point. That is monitoring, understood failure modes, authority to intervene, and documented intervention — the four things oversight actually requires.

05

The Brain — learning without forgetting its sources

The Brain is the store that makes the system feel like it teaches itself. It is also the component most likely to quietly rot, so its maintenance rules matter more than its write path.

The failure mode this design exists to prevent

Compaction is lossy. Compacting summaries of summaries is lossy compounding. Run it blindly every 30 days and by the fifth generation the Brain holds confident-sounding platitudes with no traceable origin — and no way to tell that degradation happened. The fix is not to avoid compaction. It is to make compaction additive, attributable, and triggered by evidence rather than by the calendar.

RuleBehaviour
Sources immutableGen-0 chunks are never edited or deleted by compaction. A new gen-1 chunk is written alongside them
Provenance carriedEvery compacted chunk lists the chunk IDs it absorbed. Traceable to origin at any depth
Evidence-based triggerRetrieval staleness plus near-duplicate density, not a fixed 30-day clock. A calendar is not a reason
Confidence floors downA compacted chunk inherits the minimum confidence of its parents, never the average
Generation ceilingGen ≥ 2 cannot be the sole support for a recommendation. Prevents drift becoming authority
Contradiction blocksIf any gen-0 source contradicts another, the group is not compacted — the tension is the information
First-party outcome winsA measured plane-A outcome that contradicts a Brain chunk demotes it immediately, at any generation

07

Two loops, running at different speeds

InstaMedia had one loop that closed in days: publish, engagement lands, rescore. Waters has no equivalent fast signal — a campaign resolves into pipeline over months. That is not a flaw to engineer around; it is the shape of the business, and the architecture has to admit it.

Prototype consequence

With a real 6–18 month cycle the slow loop cannot be demonstrated live. Generate roughly eighteen months of synthetic campaign and outcome history so the grading, the receipt, and the demotion of a contradicted Brain chunk are all visible on stage. Synthetic data you generate yourself needs no further approval.

09

Structural invariants

Everything above is configurable except these. They are properties of the schema and the code path, not settings.

  • Plane B has no embedding column. Raw market signal cannot reach a citation because there is no mechanism by which it could.
  • Plane A and Plane C return in separate buckets. The generator cannot merge them, and must label them differently.
  • A Plane C chunk is never sole support. Every recommendation needs at least one plane-A anchor or it is marked unvalidated.
  • One contradiction round. No code path requests a second. Disagreement escalates to a human.
  • Deterministic checks override models. A claims-screen failure is a failure regardless of what any model concluded.
  • Compaction is additive. Gen-0 sources are never rewritten or deleted.
  • Min-N gate. Below threshold the system reports insufficient baseline rather than a number — in scoring, in retrieval, and in the interface.
  • Every gate writes an immutable event carrying approver, decision, timestamp and payload hash.
  • No write path to any Waters system. Not production, not test, not QA.
